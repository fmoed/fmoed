## 🔨 What I've Built

**ProTracker** — Migrated a legacy WinForms/.NET 4.8 desktop tracker into
a cloud-native IoTaaS platform. Dual-channel telemetry ingestion (TCP/UDP/MQTT),
a GPS deduplication engine cutting redundant storage by ~95%, 17-type real-time
alert system via FCM + SignalR, multi-tenant isolation at the DB layer, and a
3-tier speed-safe vehicle immobilizer. Built solo.

**MC-AI-Core** — Multi-agent LangGraph pipeline for radiology analysis integrating
MedGemma, MedSAM, and CheXagent across CT, MRI, and X-Ray modalities.
Tested on real clinical cases. Development paused at 71% sensitivity —
a deliberate stop before the system was clinically safe enough to deploy.

**[bidiscope](https://github.com/fmoed/bidiscope)** — Open-source npm library fixing Arabic bidirectional
text rendering bugs in terminal emulators.
